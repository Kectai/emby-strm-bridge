# STRM Bridge 0.2.2

## 本次重点更新

- 支持 Adaptive 路由与普通 STRM 客户端直连。
- 支持远程 TS/M2TS 快速定位。
- 优化多次拖动进度条及重连后的播放稳定性。
- 优化多用户、多设备、多会话同时播放。
- 优化 HLS 播放连续性与网关兼容性。
- 配置页面支持简体中文、繁体中文和英文，并跟随 Emby Web 语言。

## Highlights

- Adaptive routing and direct client delivery for ordinary STRM media.
- Fast positioning for remote TS/M2TS media.
- More reliable playback after repeated seeking and reconnecting.
- Improved simultaneous playback across users, devices, and sessions.
- Improved HLS playback continuity and gateway compatibility.
- Simplified Chinese, Traditional Chinese, and English configuration UI that follows the Emby Web language.
